# Landing Page - Panorama do Mercado Tech

## Descrição
Este projeto é uma landing page acadêmica desenvolvida para apresentar
um panorama do mercado de tecnologia em Joinville/SC e no Brasil (remoto),
com base em uma pesquisa exploratória de 8 vagas de nível júnior e estágio,
coletadas entre 01/08/2026 e 04/08/2026 no LinkedIn, Infojobs e Jobsora.

## Como executar
Abra o arquivo index.html no navegador ou utilize a extensão Live Server.

## Publicação
O projeto é publicado como página estática através do GitHub Pages,
utilizando a branch main e a pasta raiz (root) como fonte de publicação.

## Evolução prevista
Nesta primeira versão, os dados são fixos no HTML. A estrutura foi
organizada para permitir, futuramente, a integração com uma API back-end
desenvolvida em Java e Spring Boot.
