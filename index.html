Competências técnicas

  • Lógica de programação e orientação a objetos
  • Versionamento de código com Git
  • Bancos de dados relacionais (PostgreSQL, MySQL, SQL Server)
  • Desenvolvimento e consumo de APIs REST
  • Noções de infraestrutura na nuvem (AWS, Azure, GCP)

Competências comportamentais

  • Autonomia, especialmente em vagas remotas
  • Boa comunicação escrita e organização
  • Adaptabilidade a novas tecnologias
  • Disciplina para documentação e padronização

Análise final

A maioria dos anúncios analisados é voltada a nível júnior e estágio. Java, JavaScript, Python e C# são as linguagens mais valorizadas, enquanto PostgreSQL e MySQL lideram entre os bancos de dados. Git, APIs REST e conhecimentos em infraestrutura na nuvem (AWS e Azure) aparecem como diferenciais técnicos tanto nas vagas locais de Joinville quanto nas oportunidades nacionais e remotas — que, por sua vez, exigem maior maturidade em computação em nuvem, engenharia de dados e práticas de CI/CD.
