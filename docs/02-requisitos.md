# Requisitos do Projeto

## Requisitos funcionais

| Código | Requisito funcional | Descrição |
|---|---|---|
| RF01 | Exibir cabeçalho | A página deve apresentar logo e menu de navegação. |
| RF02 | Apresentar introdução | A página deve conter título, descrição e chamada principal. |
| RF03 | Apresentar pesquisa | A página deve explicar o levantamento de vagas analisadas. |
| RF04 | Listar vagas locais | A página deve apresentar vagas locais em cards. |
| RF05 | Listar vagas nacionais | A página deve apresentar vagas nacionais em cards. |
| RF06 | Listar tecnologias | A página deve destacar tecnologias recorrentes. |
| RF07 | Apresentar competências | A página deve listar competências técnicas e comportamentais. |
| RF08 | Apresentar análise final | A página deve sintetizar o que o mercado exige. |
| RF09 | Exibir rodapé | A página deve apresentar disciplina, acadêmico e ano. |

## Requisitos não funcionais

| Código | Requisito não funcional | Descrição |
|---|---|---|
| RNF01 | Responsividade | A página deve funcionar em desktop, tablet e celular. |
| RNF02 | Organização | O projeto deve separar HTML, CSS, imagens, ícones e documentação. |
| RNF03 | Versionamento | O projeto deve ser versionado com Git e publicado no GitHub. |
| RNF04 | Documentação | O projeto deve possuir README e documentos na pasta docs. |
| RNF05 | Semântica | O HTML deve usar header, main, section, nav e footer. |
| RNF06 | Metadados | O head deve conter charset, viewport, title, description, favicon e manifest. |
| RNF07 | Caminhos relativos | Arquivos internos devem ser referenciados por caminhos relativos. |
| RNF08 | Publicação | A estrutura deve permitir publicação com GitHub Pages. |

## Critérios de aceite
- Todas as seções descritas nos requisitos funcionais estão presentes no index.html.
- A página é totalmente navegável em telas pequenas, médias e grandes.
- Não há caminhos absolutos (iniciados por barra) referenciando arquivos internos.
- O head contém todos os metadados exigidos pelo RNF06.
